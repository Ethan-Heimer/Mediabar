# Media Bar - Media info for Polybar
![example media bar config](mediabar.png)

Media Bar is a simple media controller for Polybar! It uses `playerctl`, so media players like Spotify and browsers like Firefox are supported.

## Modules

The mediabar.ini file defines the following modules to use in your Polybar config

- `media`: displays the current song and artist
- `media-timestamp`: displays the current timestamp of the media playing
- `media-pause`: displays a play/pause button to play/pause media
- `media-prev`: displays a button to go back to the previous track
- `media-next`: displays a button to skip to the next track 
- `media-volume`: displays a volume bar representing the volume of the current player
- `media-volume-down`: displays a button to lower the player's volume
- `media-volime-up`: displays a button to raise the players's volume
